# AI Job Description Generator & Optimizer

تطبيق MVP احترافي بـ **Python + Streamlit + OpenAI API** لإنشاء الأوصاف الوظيفية وتحسينها وتقييم جودتها، بالعربية والإنجليزية.

## النسخة المنشورة

[افتح التطبيق](https://ai-jd-studio.streamlit.app/) · [مستودع GitHub](https://github.com/caesar-441/ai-jd-studio)

تم النشر واختبار إنشاء وصف عربي وتحسين وصف إنجليزي وتحليل الجودة باستخدام OpenAI فعليًا، واختبار تنزيل TXT. راجع تقرير الاختبارات للتفاصيل والحدود.

## ما الذي يقدمه؟

- إنشاء JD من المسمى والإدارة والمستوى والقطاع والمتطلبات، مع موقع ونمط عمل اختياريين.
- تحسين وصف قائم مع عرض الأصل وملاحظات التعديل والافتراضات.
- تحليل مستقل، أو تحليل المسودة الناتجة، بدرجة من 100 ودليل وتوصية لكل معيار.
- نسخ النص باستخدام زر النسخ في مربع النص، وتنزيل TXT وMarkdown وتقرير الجودة.
- الاحتفاظ بآخر نتيجة ناجحة لكل وضع داخل الجلسة، ومسح الجلسة بضغطة.

لا يتضمن فحص السير الذاتية أو قاعدة بيانات أو Automation.

## تشغيل محلي

استخدم Python 3.12 أو 3.13. من مجلد المشروع:

```bash
python3 -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
```

افتح `.streamlit/secrets.toml` محليًا واستبدل القيمة التجريبية بمفتاحك. لا ترسله في الدردشة ولا ترفعه إلى GitHub. في Windows يمكن نسخ الملف من مستكشف الملفات.

```toml
OPENAI_API_KEY = "YOUR_PRIVATE_KEY"
OPENAI_MODEL = "gpt-4.1-mini"
```

```bash
python -m streamlit run app.py
```

افتح العنوان الذي يظهر، عادة `http://localhost:8501`. يمكن استخدام متغيرات البيئة بالاسمين نفسيهما؛ لها الأولوية على Secrets. يعمل استعراض الواجهة دون مفتاح وتتعطل أزرار طلبات AI حتى إعداده. ظهور «API configured» يعني وجود الإعداد، ولا يؤكد صلاحية المفتاح أو الرصيد.

## النشر على Streamlit Community Cloud

1. أنشئ مستودع GitHub وارفع **محتويات هذا المجلد**؛ يجب أن يكون `app.py` و`requirements.txt` في الجذر. تأكد من رفع `.streamlit/config.toml` أيضًا.
2. لا ترفع `.streamlit/secrets.toml` أو `.env` أو بيئة Python المحلية. ملف `.gitignore` يستثنيها؛ تحقق كذلك عند الرفع اليدوي.
3. افتح [Streamlit Community Cloud](https://share.streamlit.io/) وسجّل الدخول ثم اختر Create app وحدد المستودع والفرع وملف `app.py`.
4. في Advanced settings اختر Python 3.12 أو 3.13، وأضف قيمتي Secrets أعلاه بمفتاحك الحقيقي. هذه الخطوة تتم مباشرة داخل Streamlit، وليس في الدردشة أو GitHub.
5. اضغط Deploy وانتظر اكتمال البناء. انسخ رابط التطبيق `https://...streamlit.app`.
6. نفّذ اختبار القبول أدناه من الرابط المنشور، ثم من نافذة خاصة. تحقّق من إعداد مشاركة التطبيق ليتمكن المقيم من فتحه.

الدليل الرسمي: [النشر](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy)، [إدارة الأسرار](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/secrets-management).

## معايير الجودة

| المعيار | الوزن |
|---|---:|
| وضوح الدور | 20% |
| المسؤوليات | 20% |
| المؤهلات | 15% |
| المهارات | 15% |
| مؤشرات الأداء | 10% |
| الهيكلة واللغة | 10% |
| الشمول وملاءمة المتطلبات | 10% |

النموذج يعطي كل معيار درجة 0–10 مع دليل وتوصية؛ التطبيق يحسب المجموع برمجيًا: مجموع (درجة المعيار × الوزن) ÷ 10، ثم التقريب لأقرب عدد صحيح. صفر = غائب، 1–3 = ضعيف، 4–6 = جزئي، 7–8 = واضح، 9–10 = مكتمل ومحدد. هذا **تقييم تحريري إرشادي غير معتمد** وقد يختلف بين المحاولات؛ لا يقيس صلاحية المرشحين ولا يمثل رأيًا قانونيًا. لا توجد مقارنة قبل/بعد تلقائية: يمكن تحليل الأصل والنسخة المحسنة بطلبين صريحين.

## البنية والتكلفة والبيانات

`app.py` للواجهة وحالة الجلسة، و`core.py` للتحقق والمدخلات والـprompts والربط والحساب. يستخدم الربط `Responses API` و`responses.parse` مع نماذج Pydantic لضبط بنية الرد. النموذج الافتراضي `gpt-4.1-mini` قابل للتغيير إلى نموذج يدعم Responses وStructured Outputs.

كل ضغط لإنشاء أو تحسين أو تحليل ينفّذ طلبًا واحدًا مدفوعًا إلى OpenAI. عرض النتائج وتنزيلها لا يطلبان API. المدخلات محدودة إلى 16,000 حرف للوصف و4,000 حرف للمتطلبات، والمخرجات إلى 5,000 token، مع مهلة 60 ثانية ودون إعادة محاولات تلقائية. فاصل 3 ثوانٍ داخل الجلسة يمنع النقرات السريعة، لكنه **ليس حماية شاملة من إساءة استخدام رابط عام**. لإدارة ميزانية العرض استخدم إعدادات الوصول في Streamlit وراقب رصيد API؛ إعادة فتح الجلسة تتجاوز الفاصل ولا يوجد حد مالي يفرضه التطبيق.

لا يوجد تخزين دائم للأوصاف أو تسجيل لمحتواها في كود التطبيق. تبقى النتائج في ذاكرة جلسة Streamlit حتى مسحها أو انتهاء الجلسة. تُرسل المدخلات إلى OpenAI مع `store=False`؛ هذا لا يعني إلغاء كل احتفاظ لدى المزود، إذ تطبق سياساته. لا تُدخل بيانات موظفين أو أسرار شركة. المخرجات تُعرض كنص آمن دون تشغيل HTML أو صور وروابط من النموذج. راجع الإضافات المقترحة قبل اعتمادها.

مراجع الربط: [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)، [النموذج](https://developers.openai.com/api/docs/models/gpt-4.1-mini).

## الاختبارات

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

الاختبارات تستخدم استجابات محاكاة، دون مفتاح أو تكلفة. تغطي الحساب والأوزان وحدود المدخلات وصيغة طلبات API ورفض/نقص الرد وأخطاء الاتصال والمصادقة، ومسارات الواجهة والنسخ والتنزيل واستمرار النتائج ومسح الجلسة.

### اختبار القبول الحي قبل التسليم

بعد إدخال المفتاح بنفسك في Secrets:

1. أنشئ وصف «أخصائي موارد بشرية»، إدارة HR، قطاع خدمات، ومتطلبات Excel وتنسيق التوظيف. تحقق من أقسام الملخص والمسؤوليات والمؤهلات والمهارات وKPIs، ومن تمييز المقترحات.
2. حلّل المسودة. تحقق من الدرجة ومن أن الأدلة تشير للنص الفعلي.
3. انتقل للتحليل وحمّل المثال المختصر؛ تحقق أن التقرير يلاحظ غياب KPIs وتفاصيل الدور.
4. اضغط تحسين هذا الوصف. تأكد من حفظ الحقائق وإظهار ملاحظات التعديل، ثم حلّل النسخة المحسنة.
5. جرّب English، وانسخ النص، ونزّل TXT وتقرير الجودة وافتحهما للتحقق من الترميز.
6. امسح الجلسة. اختبر الرابط من نافذة خاصة وتأكد من عمل الأوضاع الثلاثة للمقيم.

هذه الخطوات الحية ضرورية لتأكيد صلاحية المفتاح وإتاحة النموذج والرصيد وجودة المحتوى الفعلي. راجع `TEST_REPORT.md` لمعرفة ما تم تنفيذه بالفعل.

## حل المشكلات

- **المفتاح مفقود:** أضفه في Secrets ثم أعد تشغيل التطبيق.
- **401 / مفتاح غير صالح:** تحقق من القيمة والصلاحية واستبدله في Secrets فقط.
- **429:** تحقق من رصيد API وحدود الاستخدام، ثم حاول لاحقًا.
- **إعداد نموذج غير مدعوم:** أعد `OPENAI_MODEL` إلى النموذج الافتراضي وتحقق من إتاحته للحساب.
- **انقطاع/مهلة:** اختصر المدخلات وأعد المحاولة؛ تبقى آخر نتيجة ناجحة ظاهرة.
- **ناتج غير مكتمل:** اختصر النص. لا يعرض التطبيق جزءًا غير متحقق منه كأنه نتيجة مكتملة.
